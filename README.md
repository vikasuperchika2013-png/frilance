# 💰 Финансовый Трекер & Ассистент (Personal Finance App)

Современное веб-приложение для удобного учёта личных финансов, планирования бюджета, накоплений и управления долгами с поддержкой голосового ввода, гибкой аналитики и sparkline-графиков динамики.

---

## 🚀 Основные возможности

### 1. 📊 Главный дашборд и аналитика
- **Сводка баланса**: наглядный расчёт текущего баланса, общих доходов и расходов за выбранный период.
- **Интерактивные диаграммы**: круговые и столбчатые графики распределения расходов по категориям.
- **Фильтрация по периодам**: за сегодня, текущую неделю, месяц, весь год или произвольный диапазон.

### 2. 💸 Учёт операций (Доходы и Расходы)
- Быстрое добавление транзакций с выбором категории, даты, типа и заметки.
- Редактирование, удаление и поиск по операциям.
- Гибкая настройка категорий (иконки, цвета, лимиты).

### 3. 🎯 Копилки и финансовые цели
- Создание целей с дедлайнами, иконками и целевыми суммами.
- Пополнение и частичное снятие с ведением подробного журнала истории.
- **Sparkline-графики**: визуализация динамики накоплений по каждой отдельной цели и общего прогресса всех копилок.
- Праздничный эффект салюта при достижении 100% цели.

### 4. 🛡️ Фонд «На чёрный день» (Финансовая подушка)
- Расчёт рекомендуемой подушки безопасности на 3–6 месяцев средних расходов.
- Внесение сбережений и экстренное снятие при форс-мажорах.
- Sparkline-график траектории фонда с линией целевого ориентира.

### 5. 💳 Кредиты и долговые обязательства
- Учёт займов и кредитов с процентными ставками и графиком ежемесячных платежей.
- Индикатор оставшейся суммы и даты погашения.

### 6. 🎙️ Голосовой ввод операций
- Распознавание команд через Web Speech API (например: *"Потратил 1500 тенге на продукты"* или *"Зарплата 250000 тенге"*).
- Автоматическое определение суммы, типа операции и подходящей категории.

### 7. 🎨 Персонализация и настройки
- **6 дизайнерских тем**: Изумрудная природа, Неоновый киберпанк, Закатный апельсин, Океанская лазурь, Королевский аметист, Минимализм.
- **Глубокий ночной режим (OLED Black)** для комфортной работы в темноте.
- **Выбор валюты**: Тенге (`₸`), Рубль (`₽`), Доллар (`$`), Евро (`€`).
- **Звуковые эффекты**: звуки монет, кликов и успешных действий на базе Web Audio API.
- **Резервное копирование**: экспорт и импорт всех данных в формате JSON.
- **PWA**: возможность установки приложения на телефон или рабочий стол.

## 🛠️ Стек технологий

- **Фреймворк**: React 18+ (TypeScript)
- **Сборщик**: Vite
- **Стилизация**: Tailwind CSS
- **Иконки**: Lucide React
- **Анимации & Эффекты**: CSS Transitions, Canvas Confetti
- **Аудио**: Web Audio API
- **Хранение данных**: LocalStorage + JSON Export/Import

## 💻 Локальный запуск и разработка

1. **Установка зависимостей**:
   ```bash
   npm install
   ```

2. **Запуск в режиме разработки**:
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу `http://localhost:3000`.

3. **Проверка типов и линтинг**:
   ```bash
   npm run lint
   ```

4. **Сборка для продакшена**:
   ```bash
   npm run build
   ```

## 📱 Установка как PWA

Приложение поддерживает работу в режиме прогрессивного веб-приложения:
- В браузере нажмите кнопку **«Установить приложение»** в шапке или боковом меню.
- На смартфонах доступно добавление на главный экран (*Add to Home Screen*).
